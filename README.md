# Library Management System

A simple and beginner-friendly Library Management System built using Python and Object-Oriented Programming (OOP).

## Features

- Add new books with unique Book IDs
- View all available books
- Search books by ID or title
- Issue books to students
- Return issued books
- View all issued books
- Remove books from the library
- Input validation and duplicate ID checking

## Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- Classes and Objects
- Lists, Loops and Conditional Statements

## How to Run

1. Install Python 3 on your computer.
2. Clone this repository:

```bash
git clone https://github.com/YOUR-USERNAME/Library-Management-System.git
```

3. Open the project folder in VS Code.
4. Run the application:

```bash
python library_management.py
```

## How It Works

The application provides a menu-driven interface that allows users to manage books through the terminal.

Users can add, search, issue, return and remove books using the available menu options.

## Limitations

- Book records are stored in memory and reset when the program exits.
- The application currently uses a command-line interface.
